# 账号配置

::: tip 提示
OCR Pro 提供了独立的账号系统，用户可以通过后台管理自己的 API Key 和使用额度。
:::

## 第一步：获取账号

### 1. 登录 uTools

确保你已经登录了 uTools 账号。

::: warning 注意
如果未登录 uTools，将无法使用 OCR Pro 的账号系统功能。
:::

### 2. 首次使用自动注册

当你首次使用 OCR Pro 时，插件会自动为你创建账号：

1. 打开 OCR Pro 插件
2. 系统自动获取你的 uTools 用户信息
3. 自动在后台创建对应账号
4. 自动生成登录密码并保存到本地（点击标题“用户信息”即可查看）
5. 自动赠送初始额度（18.8元，约188次使用）

::: tip 提示
整个注册过程是自动完成的，无需手动操作。首次使用后，你的账号信息会保存在本地。
:::

---

## 第二步：登录后台

### 1. 访问后台地址

打开浏览器，访问 OCR Pro 的后台管理地址：

```
https://keys.jlws.top
```

### 2. 查看登录凭证

你的登录凭证信息已自动保存在插件中：

「基础配置」页面>「个人中心」页面，右侧的账号区域，点击标题“用户信息”，即可查看账号信息

::: warning 重要
如果你更换了设备或清除了插件数据，密码将无法恢复。此时需要联系管理员重置密码。
:::

### 3. 登录步骤

1. 在登录页面输入用户名和密码
2. 点击「登录」按钮
3. 登录成功后进入后台管理界面

---

## 第三步：获取 API Key

### 1. 进入令牌管理

登录后台后，在左侧菜单中找到「令牌」选项，点击进入令牌管理页面。

### 2. 创建新令牌

1. 点击「创建新令牌」按钮
2. 填写令牌名称（例如：OCR Pro）
3. 选择令牌权限（保持默认即可）
4. 点击「确定」按钮

### 3. 复制令牌

创建成功后，系统会显示生成的 API Key。

::: danger 警告
API Key 妥善保管，不要泄露。
:::

点击「复制」按钮，将 API Key 复制到剪贴板。

---

## 第四步：在插件中配置

### 1. 打开插件设置

在 OCR Pro 插件中：
- 点击主界面的设置按钮
- 进入插件「模型服务」页面

### 2. 找到 API Key 配置

在OCR Pro配置页面中，找到「API Key」的表单。

### 3. 填写 API Key

1. 将刚才复制的 API Key 粘贴到输入框中
2. 点击「保存」按钮
3. 点击测试验证 API Key 的有效性

### 4. 验证配置

配置成功后：
- 在「个人中心」查看账号状态
- 查看剩余额度是否正常显示
- 尝试使用 OCR 功能测试是否正常工作

---

## 常见问题

### 1. 如何查看我的用户名和密码？

- 「**基础配置**」页面>「**个人中心**」页面，右侧的账号区域，点击标题“用户信息”，即可查看账号信息

### 2. 忘记密码怎么办？

如果忘记了后台登录密码：
1. 检查插件本地是否有保存
2. 如果更换了设备或清除了数据，密码无法恢复
3. 请联系管理员重置密码

### 3. API Key 丢失了怎么办？

如果 API Key 丢失：
1. 登录后台管理界面
2. 删除旧的令牌
3. 创建新的令牌
4. 在插件中重新配置新的 API Key

### 4. 额度不足怎么办？

当额度不足时：
1. 等待每日免费额度重置（每天 0 点重置 5 次）
2. 购买会员套餐获得更多额度
3. 购买额度包补充使用次数
