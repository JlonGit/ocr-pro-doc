## 1. 注册登录

[点击此处跳转网页](https://www.volcengine.com/)

注册火山引擎账号并登录（如需实名认证，按提示完成即可）

## 2. 实名认证

进入 [「账户中心」](https://console.volcengine.com/user/account)

点击「实名认证」

选择「个人」或「企业」认证

按照提示完成身份验证

::: tip 提示
实名认证是使用付费服务的前提条件
:::

## 3. 开通大模型服务

进入 [「火山引擎控制台」](https://console.volcengine.com/)

在左侧菜单找到「火山方舟」

点击「立即开通」按钮

阅读服务协议并同意

## 4. 创建 API Key

进入 [「API 密钥」](https://console.volcengine.com/iam/keymanage/)

点击「创建新的访问密钥」

系统会生成 API Key

复制生成的 API Key 并妥善保管

::: warning 重要
API Key 只会显示一次，请立即复制并妥善保管
:::

## 5. 查看使用情况

进入 [「账户中心」](https://console.volcengine.com/user/overview)

可以查看当前的使用情况、剩余额度和消费记录

## 6. 填写 API Key

在 OCR 应用的 模型服务 > 大模型 中，选中「火山引擎」，然后将刚才获取到的 API Key 填写到对应位置即可。

## 模型选择

| 模型 | 特点 | 推荐场景 |
|------|------|---------|
| doubao-pro-4k | 旗舰模型，能力最强 | 复杂任务、OCR 识别 |
| doubao-pro-32k | 长上下文版本 | 长文本处理、文档分析 |
| doubao-lite-4k | 轻量版本，速度快 | 简单任务、高频调用 |
| doubao-vision-pro | 视觉多模态模型 | 图像理解、OCR 识别 |

## 常见问题

### 1. 实名认证失败

- 确保提交的身份信息真实有效
- 检查身份证照片清晰度
- 等待审核完成（通常 1-2 小时）

### 2. 开通服务后无法使用

- 确保已完成实名认证
- 检查是否已绑定支付方式
- 刷新页面或重新登录

### 3. API Key 无法使用

- 确保 API Key 已正确复制
- 检查是否已绑定支付方式
- 确认账户有足够的余额或额度

### 4. 如何获得更多免费额度

- 完成实名认证可获得初始免费额度
- 邀请朋友使用可获得奖励
- 参与官方活动获得体验金

### 5. 模型选择建议

- OCR 识别：使用 `doubao-vision-pro` 或 `doubao-pro-4k`
- 复杂推理：使用 `doubao-pro-4k`
- 高频调用：使用 `doubao-lite-4k`
