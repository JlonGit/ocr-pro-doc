# 火山引擎 LLM

::: warning 注意
本文信息可能会过时，仅供参考，请以服务商最新官方文档为准。

官方文档：https://www.volcengine.com/docs/82379/1099475
:::

火山引擎的豆包大模型，字节跳动旗下，国内领先的 LLM 服务。

## 1. 注册登录

[点击此处跳转网页](https://www.volcengine.com/)

注册火山引擎账号并登录（如需实名认证，按提示完成即可）

## 2. 实名认证

进入 [「账户中心」](https://console.volcengine.com/user/account)

点击「实名认证」

选择「个人」或「企业」认证

按照提示完成身份验证

::: tip 提示
实名认证是使用付费服务的前提条件
:::

## 3. 开通大模型服务

进入 [「火山引擎控制台」](https://console.volcengine.com/)

在左侧菜单找到「火山方舟」

点击「立即开通」按钮

阅读服务协议并同意

## 4. 绑定支付方式

进入 [「账户中心 - 支付方式」](https://console.volcengine.com/user/payment)

点击「添加支付方式」

选择支付方式（信用卡、借记卡等）

填写相关信息并完成验证

::: tip 提示
绑定支付方式后才能使用付费模型
:::

## 5. 创建 API Key

进入 [「API 密钥」](https://console.volcengine.com/iam/keymanage/)

点击「创建新的访问密钥」

系统会生成：
- **API Key**：访问密钥 ID
- **Secret Key**：秘密访问密钥

::: warning 重要
秘密访问密钥只会显示一次，请立即复制并妥善保管
:::

## 6. 查看使用情况

进入 [「账户中心」](https://console.volcengine.com/user/overview)

可以查看当前的使用情况、剩余额度和消费记录

## 7. 填写 API Key

在 OCR 应用的 模型服务 > 大模型 中，选中「火山引擎」，然后将刚才获取到的 API Key 填写到对应位置即可。

## 常见问题

### 1. 实名认证失败

- 确保提交的身份信息真实有效
- 检查身份证照片清晰度
- 等待审核完成（通常 1-2 小时）

### 2. 开通服务后无法使用

- 确保已完成实名认证
- 检查是否已绑定支付方式
- 刷新页面或重新登录

### 3. API Key 无法使用

- 确保 API Key 已正确复制
- 检查是否已绑定支付方式
- 确认账户有足够的余额或额度

### 4. 如何获得更多免费额度

- 完成实名认证可获得初始免费额度
- 邀请朋友使用可获得奖励
- 参与官方活动获得体验金

### 5. 模型选择建议

- OCR 识别：使用 `doubao-vision-pro` 或 `doubao-pro-4k`
- 复杂推理：使用 `doubao-pro-4k`
- 高频调用：使用 `doubao-lite-4k`
- 长文本处理：使用 `doubao-pro-32k`

### 6. 如何降低成本

- 使用轻量级模型（如 `doubao-lite-4k`）
- 优化 prompt，减少 token 使用
- 使用批量 API 获得折扣
